Суулгац

Хамт суулгах

Нэмэлт тохиргоо шаардлагагүй — хоёуланг нэг chart дээр нэмэхэд л болно. Хоёр indicator бие биенээ мэддэг байхаар урьдчилан тохируулагдсан тул давхардал үүсэхгүй:

  • Sweep marker давхардахгүй — Sniper-ийн sweep marker default OFF байдаг, учир нь ICT VISUAL liquidity sweep-ийг ягаан ✕-ээрээ аль хэдийн зурдаг.
  • Label-ууд мөргөлдөхгүй — Sniper-ийн баруун захын TP / SL / Trend Line label-ууд ICT-ийн tag эгнээний завсарт байрладаг.
  • Өнгө андуурагдахгүй — Sniper-ийн анхааруулгын өнгө amber (шаргал). ICT VISUAL дээр улбар шар нь «entry зон» гэсэн утгатай тул хоёр өнгө хоорондоо холилдохгүй.
Тохиргоо цөөн байгаа нь санаатай

Sniper-ийн Settings зориудаар цөөн — нийт 14 тохиргоо. Нарийн tuning нь 1m XAU scalp-д зориулж кодод шингэсэн тул хэрэглэгч оролдох шаардлагагүй, default-оороо бэлэн.

Timeframe

Хослол нь 1m scalp-д зориулагдсан. ICT VISUAL-ын session / killzone хэмжүүрүүд 4H хүртэлх timeframe дээр утгатай хэвээр байдаг тул дээд зэргийн зураг харахдаа ICT-ийг өндөр TF дээр ч ашиглаж болно — гэхдээ гүйцэтгэлийн (Sniper) талбар нь 1m.

Урсгал

1m scalp workflow — гурван алхам

1 · Контекст — «ажиллах цаг мөн үү?»

ICT VISUAL-ын доод панелээс хоёр зүйл шалга: killzone идэвхтэй эсэх, мөн Sp/ATR зардлын нүд ногоон эсэх (спрэд нь ATR-ийн ≤10% бол эрүүл, >25% бол scalp огт хийхгүй). Хоёулаа зөв бол ARMED зон (A эсвэл B зэрэглэл) үүсэхийг хүлээнэ.

2 · Давхцал — «зөв газар + зөв мөч»

Үнэ ARMED зоны CE-д хүрэх үед Sniper-ийн entry (🎯 score 4+) мөн гарч ирвэл давхцал бүрдэнэ — энэ бол combo-гийн хүлээж байсан мөч. ICT нь «үнэ зөв газраа ирлээ» гэж, Sniper нь «нөхцөлүүд оноо хангалаа» гэж тус тусдаа баталж байгаа хэрэг.

3 · Гүйцэтгэл — Sniper-ийн шугамуудыг дагана

Орсны дараа шийдвэр гаргах ажил байхгүй — Sniper-ийн TP1–TP4 шугам ба SL-ийг дагана. Default нь TP1-д бүрэн гардаг scalp горим; TP1 хүрсний дараа SL автоматаар breakeven болж, үлдсэн зам эрсдэлгүй болдог. 

1. КОНТЕКСТ    ICT панель:  killzone ✓ · Sp/ATR ногоон ✓ → ARMED (A/B) хүлээ
2. ДАВХЦАЛ     үнэ ARMED зоны CE-д + Sniper 🎯 4+ → орох боломж
3. ГҮЙЦЭТГЭЛ   Sniper TP1–TP4 · SL дагана → TP1 дараа SL = breakeven
Combo-гийн гол дүрэм

Хоёр indicator зөрвөл орохгүй. Жишээ нь ICT VISUAL SELL setup зурсан байхад Sniper LONG өгвөл — энэ давхцал биш, зөрчил. Аль нэгийг нь «зөв» гэж таамаглаж орохын оронд дараагийн давхцлыг хүлээ. Combo-гийн бүх давуу тал энэ ганц дүрмээс эхэлдэг.

Мэдэгдэл

Alert хослуулах

Хоёр indicator-ын alert-ийн зохион байгуулалт өөр өөр тул TradingView дээр тус тусад нь тохируулна:

KHAN SNIPER PRO — alertcondition тус бүрээр

Sniper-ийн alert бүр тусдаа alertcondition — TradingView-ийн Create Alert цонхны Condition жагсаалтаас хэрэгтэйгээ сонгоно:

  • LONG / SHORT — энгийн оноотой entry
  • SNIPER LONG / SHORT — 🎯 4+ оноотой entry
  • SWEEP LONG / SHORT — ◆ sweep-reversal entry
  • TP hit — TP түвшинд хүрэхэд
  • Printed — TP4-өөс давсан үр дүн
  • SL touched / SL hit — стоп шүргэх / батлагдах

Telegram-д зориулсан JSON payload горимтой — webhook-оор шууд илгээхэд бэлэн бүтэцтэй мессеж гаргана.

KHAN ICT VISUAL — нэг alert бүгдийг барина

ICT-ийн бүх event (MSS · SETUP ARMED · ZONE TOUCHED · SETUP EXPIRED · SMT · SB FVG) нэг «Any alert() function call» alert-аар бүгд ирдэг — event тус бүрд тусдаа alert үүсгэх шаардлагагүй. 

SNIPER PRO:  Create Alert → Condition: хэрэгтэй alertcondition-оо сонго
ICT VISUAL:  Create Alert → "Any alert() function call"  ← нэг alert = 6 event
Зөвлөмж — хамгийн бага, хамгийн чухал хос

ICT-ийн ARMED alert + Sniper-ийн SNIPER entry alert хоёрыг хоёуланг нь тавь. ARMED ирэхэд «хүлээх газар бэлэн боллоо» гэж мэдээд, SNIPER entry нь ARMED зоны ойролцоо ирвэл — давхцал бүрдлээ, тэр үед нь ор.
